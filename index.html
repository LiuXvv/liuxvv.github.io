Getting Started with OpenClaw - My AI Assistant Setup

I’ve been experimenting with OpenClaw, an open-source AI assistant that runs locally on your own hardware. Unlike cloud-based assistants, OpenClaw gives you full control over your data and workflows.

Why OpenClaw?

The main appeal for me was privacy and customization. I wanted an assistant that could:

  • Access my local files and tools
  • Integrate with my existing workflow
  • Not send everything to the cloud
  • Be customizable to my needs

My Setup

I configured OpenClaw with several skills:

  • gog — Google Workspace integration (Gmail, Calendar, Drive)
  • apple-notes — Managing Apple Notes via AppleScript
  • weather — Quick weather checks
  • Tavily — Web search capabilities

The Personality Configuration

One of the coolest parts is defining your assistant’s personality. I set mine to be:

  • Playful but straightforward
  • Chill and low-key
  • Creative yet reliable
  • Helpful with gentle English corrections

What’s Next?

I’m planning to add more automation workflows and maybe build some custom skills. The possibilities are endless when you control the infrastructure.

Have you tried running your own AI assistant? I’d love to hear about your setup!

Why I Switched to GitHub Pages for My Blog

After maintaining a self-hosted blog for years, I finally made the switch to GitHub Pages. Here’s why it was the right decision for me.

The Old Setup

Previously, I had my blog on a custom domain with a VPS. It worked fine, but there were ongoing concerns:

  • Domain renewal costs — Annual fees add up
  • Server maintenance — Security updates, SSL certificates
  • Backup responsibility — Everything was on me

Why GitHub Pages?

1. Free Hosting

GitHub Pages is completely free for public repositories. No server costs, no domain fees (if you use the github.io subdomain).

2. Built-in CDN

Your site is distributed globally via GitHub’s CDN. Fast loading anywhere in the world.

3. Version Control

Since it’s just a Git repo, every change is tracked. Made a mistake? Just revert the commit.

4. Easy Deployment

Push to the repository and your site updates automatically. No FTP, no SSH, no manual uploads.

The Migration Process

Moving from my old setup was straightforward:

  1. Export content from old platform
  2. Set up Hexo (my static site generator of choice)
  3. Configure GitHub Pages
  4. Update DNS (I kept my custom domain initially)
  5. Test and verify everything worked

Custom Domain vs. GitHub.io

I started with my custom domain hetao-ai.cn, but when it expired, I decided to just use the default liuxvv.github.io. It’s simpler and one less thing to manage.

Final Thoughts

For a personal tech blog, GitHub Pages hits the sweet spot of simplicity, reliability, and cost. I can focus on writing instead of server administration.

If you’re considering starting a blog, I’d definitely recommend checking out GitHub Pages or similar static hosting options.

Building a Personal Knowledge Base with AI

In the age of information overload, having a personal knowledge base is more important than ever. Here’s how I’m using AI to make mine smarter and more useful.

The Problem

We consume so much content every day:

  • Articles and blog posts
  • Documentation and tutorials
  • Books and podcasts
  • Meeting notes and ideas

But where does it all go? For most people, it disappears into the void. Read once, remember never.

My Solution

I’ve been building a system that combines:

  1. Apple Notes — Quick capture on any device
  2. GitHub Repos — Code snippets and configurations
  3. AI Assistant — Organization and retrieval

How AI Helps

Smart Organization

Instead of manual tagging, I can ask my AI to:

  • “Find all notes about Python async”
  • “Summarize my meeting notes from last week”
  • “What did I learn about Docker?”

Contextual Reminders

The AI can surface relevant past notes when I’m working on something related. It’s like having a second brain that actually remembers things.

Natural Language Search

No more rigid folder structures. Just ask in plain language and get results.

Tools I’m Using

  • OpenClaw — My local AI assistant
  • Apple Notes — Native, fast, syncs everywhere
  • GitHub — Version-controlled configs and code
  • Tavily — Web search for external knowledge

The Future

I envision a system where:

  • Everything I learn is automatically captured
  • The AI finds connections I might miss
  • Knowledge is retrieved exactly when needed
  • Insights are surfaced proactively

We’re not quite there yet, but the pieces are coming together.

Your Turn

How do you manage your personal knowledge? Are you using any AI tools to help? I’d love to hear your setup!
